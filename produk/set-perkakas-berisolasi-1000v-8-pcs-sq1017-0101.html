Deskripsi ProdukProduct Description

Set perkakas dielektrik 1000V isi 8 pcs berisi tang dan obeng berisolasi untuk teknisi listrik. Seluruh bagian logam terbuat dari baja CR-V dan gagangnya berisolasi untuk pekerjaan pada instalasi bertegangan.
